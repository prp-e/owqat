About IANA time zones

The IANA database tracks local clock rules using names such as Europe/Dublin. Choose a city for its own prayer times. The default uses the zone’s reference location.

دربارهٔ مناطق زمانی آیانا

پایگاه دادهٔ آیانا قواعد ساعت محلی را با نام‌هایی مانند Europe/Dublin ثبت می‌کند. برای اوقات شرعی دقیق‌تر، شهر خود را انتخاب کنید. حالت پیش‌فرض از موقعیت مرجع منطقه استفاده می‌کند.

نبذة عن المناطق الزمنية في قاعدة آيانا

تسجّل قاعدة بيانات آيانا قواعد التوقيت المحلي بأسماء مثل Europe/Dublin. اختر مدينتك لعرض مواقيت الصلاة فيها. يستخدم الخيار الافتراضي الموقع المرجعي للمنطقة الزمنية.
